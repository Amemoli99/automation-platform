          Cosa è collegato a questo computer e cosa carica il progetto agganciato: programmi, server MCP, skill e agent, hook e script. Sola lettura: di ogni server si vedono i nomi delle variabili richieste, mai i valori.
          
    
          
    
          
    
          Programmi sul computer
          Gli strumenti che servono per lavorare con la pipeline e con i server MCP del progetto.
          
    
          Server MCP
          Letti da .mcp.json del progetto e dalle sue impostazioni. “Verifica stato” avvia davvero i server (qualche secondo) e mostra anche i connettori del tuo account.
          
    
          Skill
          In .claude/skills e .claude/commands. “Nel kit” significa che il Cockpit ha una skill con lo stesso nome (il contenuto può essere diverso).
          
    
          Agent
          In .claude/agents: i sotto-agenti che le skill possono chiamare.
          
    
          Hook e script
          Gli hook agganciati agli eventi di claude (da settings) e i file in .claude/hooks e .claude/scripts. “Registrato” = citato da un hook.
          
    
          Aggiungi al progetto
          Server MCP e pezzi del kit che il progetto non ha ancora. Si scrive solo nel progetto (.mcp.json, .claude): non si installa nulla e non si sovrascrive mai ciò che esiste. Serve il profilo Administrator.
          
    
          Cerca altri server MCP
          Dal registro ufficiale MCP (registry.modelcontextprotocol.io): decine di migliaia di server per ogni ambito (repository, database, cloud, documenti, browser…). Sono di terze parti: il registro verifica chi possiede il nome, non il codice. Qui non si installa nulla: si scrive solo la voce in .mcp.json, ma npx/uvx scaricano ed eseguono il pacchetto al primo uso. Serve internet.
